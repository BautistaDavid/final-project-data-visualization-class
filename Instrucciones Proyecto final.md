# Instrucciones Proyecto final

## Pasos

1. **Revisar la encuesta.** Revise la encuesta cargada como adjunto, que hace parte del estudio de apropiación de las tecnologías digitales. Este enlace le permitirá conocer cada una de las preguntas y las posibles opciones de respuesta.

2. **Revisar la estructura de datos.** Revise el archivo de Excel que tiene la estructura y la codificación de cada una de las preguntas.

3. **Poblar la base de datos.** Realice el poblamiento (puede ser aleatorizado) de la base de datos hasta llegar a **500 registros**. Este archivo deberá ser cargado en la entrega.

4. **Construir el tablero.** Construya un tablero con visualización de datos que incluya al menos **5 tipos diferentes de recursos** (gráficos bajo el concepto de *dashboard*) y en diálogo con el informe entregado en el numeral previo. Tenga en cuenta:
   - Narrativas digitales (*storytelling*).
   - Heurísticas de diseño para la visualización de datos.
   - Manejo del color y de las formas.

5. **Elaborar el informe ejecutivo.** Realice un informe ejecutivo de visualización de datos, de **mínimo 8 y máximo 10 páginas**, que incluya:
   - Contexto
   - Indicadores de gestión
   - Modelo
   - Descripción de variables
   - Principales hallazgos
   - Referentes visuales de visualización de datos

   Un orden sugerido puede contener: título, nombre de los estudiantes con programa, resumen ejecutivo, cuerpo de texto y referencias de consulta.

6. **Desarrollar la presentación.** Desarrolle una presentación para el profesor y los compañeros de clase:
   - Tiempo de sustentación: **20 minutos** (se tomará el tiempo).
   - Debe incluir una **actividad de grupo**.
   - Debe incluir una **presentación alternativa** que evite mecanismos convencionales como PPT, Canva, Prezi, entre otros.

7. **Entregar.** Cargue todos los recursos producidos (tablero, presentación, archivo de datos) en un **único archivo .zip**.

## Resumen de entregables

| Entregable | Requisitos clave |
|---|---|
| Base de datos | 500 registros (puede ser aleatorizada) |
| Tablero | Al menos 5 tipos de gráficos, con *storytelling*, heurísticas de diseño y manejo de color y formas |
| Informe ejecutivo | 8 a 10 páginas: contexto, indicadores de gestión, modelo, variables, hallazgos y referentes visuales |
| Presentación | 20 minutos, con actividad de grupo y formato alternativo (no PPT, Canva ni Prezi) |
| Entrega final | Un único archivo `.zip` con tablero, presentación y archivo de datos |
